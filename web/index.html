adcp-test

Test your AdCP integration

The integration test suite for AdCP buyer and seller agents. Everything here runs locally — no telemetry, no uploads. Pick a capability to get started.

Conformance

Run the 24-check suite against a seller endpoint: tool surface, schemas, auth, error taxonomy — plus protocol fuzzing.

Inspect

Record live MCP traffic through a proxy, inspect every tool call on a timeline, save cassettes, replay them deterministically.

Mock builder

Config-driven fake sellers for testing buyer agents: routes, latency profiles, fault injection, lifecycle state machine.

Scenarios

Runnable scenario packs with per-step assertions, chaos mode, and full media-buy lifecycle checks.

Load

Hammer an endpoint with concurrent virtual users, live latency/throughput charts, and threshold gates.

Signdebug

Debug RFC 9421 signature rejections: reconstruct the signature base and pinpoint exactly what mismatches.

Webhooks

Capture webhook deliveries on a localhost listener and inspect headers and bodies on a timeline.

Snapshots

Save named run reports and diff two snapshots to see which checks flipped.

Reports

Assemble self-contained HTML or PDF evidence packs from your run reports.

API

Health check: /api/health

Conformance: POST /api/conformance/run with {"target_url": "https://seller.example/mcp"}

Inspect: GET /api/sessions, POST /api/record/start, POST /api/record/stop, GET /api/cassettes, POST /api/replay/start, POST /api/replay/stop

Mock builder: GET/PUT /api/mock/config, POST /api/mock/validate, POST /api/mock/start, POST /api/mock/stop, POST /api/mock/record, POST /api/mock/record/finish

Scenarios: GET /api/scenarios, POST /api/scenarios/run with {"pack": "happy-path-media-buy", "target_url": "https://seller.example/mcp"}

Load: GET /api/load/presets, POST /api/load/run, GET /api/load/results/{id}

Signdebug: POST /api/signdebug/verify with {"request": {"method": "POST", "url": "…", "headers": {}, "body": "…"}, "key_pem": "…"} — the key is used in memory only, never stored.

Lifecycle: POST /api/lifecycle/run with {"target_url": "…"}

Fuzz: POST /api/fuzz/run with {"target_url": "…", "iterations": 200}

Webhooks: POST /api/webhooks/listen, GET /api/webhooks/deliveries, POST /api/webhooks/clear, POST /api/webhooks/stop

Snapshots: GET /api/snapshots, POST /api/snapshots/save, GET /api/snapshots/diff?before=&after=, POST /api/snapshots/delete

Reports: POST /api/reports/build with report JSON fields and "format": "html"|"pdf" — returns the evidence pack as a download.

Conformance

Point at a seller agent's MCP endpoint and run the conformance suite: tool surface, input schemas, auth behavior, error taxonomy.

Probes are read-only observations of how the endpoint responds. The unsigned and malformed-signature probes use deliberately invalid arguments, so a conforming seller can never act on them.

Protocol fuzz

Throw malformed and random JSON-RPC payloads at the endpoint and record crashes, hangs, and non-JSON responses. Localhost targets only, unless you tick allow-remote.

Inspect

Record live MCP traffic through a proxy, inspect every tool call on a timeline, save cassettes, and replay them as a fake seller.

Signing debugger

      
Paste a signed HTTP request and the verification key: the debugger
         reconstructs the RFC 9421 signature base, verifies the signature, and
         pinpoints exactly what mismatches. The key is used in memory
         for this one check only — it is never stored, logged, or sent
         anywhere else.
